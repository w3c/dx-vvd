# The Variable Description Vocabulary

This repository contains the *Variable Description Vocabulary* (VVD) work of the *Dataset Exchange Working Group* (DXWG).

- [DXWG's home page](https://www.w3.org/groups/wg/dx/)
    - includes information on how to participate
- [Charter](https://www.w3.org/2026/04/dx-wg-charter.html)
    - provides the scope of the Working Group, including for this deliverable
